# Налоги·BY — калькулятор налогов Беларуси 2026

Бесплатный онлайн-калькулятор для Республики Беларусь. Работает целиком в браузере, без серверов и сбора данных.

**Live:** https://zxkittenxd.github.io/nalogi-by/

## Возможности

- 💼 **Зарплата**: gross → net и net → gross (подбор с точностью до копейки), ФСЗН 1%, подоходный 13%, стандартный вычет 216 руб. (при доходе ≤ 1 308 руб./мес), вычеты на детей 63/120 руб.
- 🧾 **НПД** (самозанятые): ставки 10%/20% (4%/8% для пенсионеров), лимит 60 000 руб./год для доходов от белорусских организаций, минимальный платёж 45 руб./мес (18 руб. для пенсионеров) — действует с 01.07.2026.
- 📈 **Сверхдоходы**: прогрессивная шкала 2026 года — 13% до 350 000 руб., 25% до 600 000 руб., 30% свыше (отдельная шкала 13/25% для дивидендов), расчёт доплаты по декларации.
- Шаринг расчёта через URL-параметры, копирование в буфер, печать, тёмная тема.

## Актуальность параметров

Все ставки и вычеты вынесены в объект `P` в начале `app.js` — при изменении законодательства правится только он. Параметры приведены по НК РБ на 2026 год (Закон № 127-З от 30.12.2025), источники: [nalog.gov.by](https://nalog.gov.by).

## Локальный запуск и тесты

```bash
python3 -m http.server 8000   # открыть http://localhost:8000
node test.js                  # 40 unit-тестов расчётов
```
